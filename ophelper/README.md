# ophelper

Helpers for writing ops, for any collection of ops and any runner. numpy and
[opspec](../opspec) only.

| Module | For |
|---|---|
| `ophelper.boxes` | building and converting box outputs (`BoxesOf`) |
| `ophelper.masks` | building and converting mask outputs (`MasksOf`) |
| `ophelper.assets` | downloading model weights once, into a shared cache |
